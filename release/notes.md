# 账号重新授权 v0.1.5

修复 RS 桌面授权外层链接被误判为“OAuth state 校验失败”的问题，提供 Linux x86_64 安装包和 SHA-256 校验文件

## 修复

- 安全解析 RS 返回的桌面授权外层链接，从 `authorize_url` 取出内部 OAuth 链接，再交给原始上游协议处理，同时保留直接 OAuth 链接兼容性
- 保留 RS 生成的 state、PKCE、client_id 和回调地址，不重新生成或替换授权参数，不跳过回调 state 校验
- 严格检查内外层可信地址、唯一且非空的参数、S256 和本地回调端口，拒绝伪造来源、重复参数和递归包装
- 将“授权链接格式无效”与真正的回调 state 不匹配区分显示，避免登录前失败被误报为回调校验失败
- 运行环境自检新增离线桌面授权链接解析检查；SDK 场景改用 RS 实际链接格式，新增未修改上游 OAuth 代码的离线传输集成测试
- 制品校验进一步核对内嵌协议源码，防止源码已修复但安装包仍包含旧适配代码
- 宿主兼容清单扩展至 `<3.28.0`，已在 RS v3.27.1 实际验证安装和环境自检
- 继续保留 v0.1.4 的私有运行目录及正常退出清理修复，不修改网关挂载、安全选项或 CPU/内存配置
- 已安装旧版本的用户请上传此版本并确认切换到 v0.1.5；旧的失败记录保留，不会自动重试

## 功能

- 从原账号备注读取邮箱、密码和验证器密钥，沿用账号绑定代理进行协议登录
- 使用 RS 原生授权流程换取并保存新授权，保留原启用状态、分组和代理
- 支持会员与状态筛选、分页、单号处理、串行批量队列、进度和取消
- 不显示或导出 RT，Free 账号、未绑定代理、在途请求及并发配置变化均有保护
- 运行包自带 Linux Python 和依赖，不依赖重登站或服务器安装依赖

## 安装范围

- 插件 ID：`personal.reauth-manager`
- 宿主清单兼容：RS `>=3.26.2, <3.28.0`
- 平台：Linux x86_64，插件入口要求 glibc 2.28+
- GitHub 安装仓库：`Lemon-57/rs-reauth-manager`
- 版本标签：`v0.1.5`，或留空查询最新正式发行版
- 附件中的 `.tar.gz` 是安装包，Source code 不是安装包
- 插件数据盘须可写、可执行，并至少预留 256 MiB 空间
