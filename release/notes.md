# 账号重新授权 v0.1.3

修复 RS v3.26.2 隔离管理页面加载失败，提供 Linux x86_64 安装包和 SHA-256 校验文件

## 修复

- 移除空 favicon 的 `data:` 引用，避免宿主提示“插件资源地址不受支持”
- 制品检查新增 HTML 页面资源校验，拒绝外部地址、未声明资源和非经典脚本等不兼容引用
- 新增 5 项页面资源回归测试，不修改授权逻辑，不放宽宿主 CSP 或 iframe sandbox
- 已安装 v0.1.2 的用户请安装此版本，并在宿主确认切换到 v0.1.3

## 功能

- 从原账号备注读取邮箱、密码和验证器密钥，沿用账号绑定代理进行协议登录
- 使用 RS 原生授权流程换取并保存新授权，保留原启用状态、分组和代理
- 支持会员与状态筛选、分页、单号处理、串行批量队列、进度和取消
- 不显示或导出 RT，Free 账号、未绑定代理、在途请求及并发配置变化均有保护
- 运行包自带 Linux Python 和依赖，不依赖重登站或服务器安装依赖

## 安装范围

- 插件 ID：`personal.reauth-manager`
- 宿主清单兼容：RS `>=3.26.2, <3.27.0`
- 平台：Linux x86_64，插件入口要求 glibc 2.28+
- GitHub 安装仓库：`Lemon-57/rs-reauth-manager`
- 版本标签：`v0.1.3`，或留空查询最新正式发行版
- 附件中的 `.tar.gz` 是安装包，Source code 不是安装包

## 验证与限制

已在 RS v3.26.2 验证实际安装、管理页加载、真实账号列表、会员筛选、分页和窄屏布局
本机构建及校验通过，包含 15 项 SDK 协议场景、16 项 Python 测试、9 项前端桥场景和源码约定检查
当前仍为实验性功能，尚未用真实账号验证完整登录与写回链路
