# v0.1.30

新增受保护的单号 `api/import` 插件入口，用于新增 OpenAI OAuth 账号：完整目录去重后，通过 RS 原生 OAuth start 建立 flow，插件使用三字段备注和分配的固定代理取得授权码，再由 RS 原生 OAuth complete 一次性保存 RT、备注、停用状态和目标分组。插件不保存新增账号密码或 2FA，不自行交换 RT，也不复用其他账号代理。

新增账号完成后必须读回邮箱、用户/工作区、Team/Business 套餐、RT、备注、代理和分组；默认保持停用，待人工核对后再启用。

# v0.1.29

修复账号原本处于 RS `quota_exhausted` 或 `rate_limited` 时，授权完成、设备退出及 RT 刷新均成功，但最终调度状态回读被错误判为未确认的问题。最终校验现在接受 RS 的稳定状态 `normal`、`disabled`、`quota_exhausted`、`rate_limited`，仍拒绝 `error`、未知状态和凭据/身份不一致。

保持 v0.1.28 的原版浏览器候选池、OAuth 指纹切换、验证码等待和 RS 原生 OAuth 完成链路。

# v0.1.28

对照 reauth-web 原版默认配置修复登录适配层差异：恢复浏览器候选池及每次新会话的随机选择，沿用原版 OAuth 请求候选处理；邮箱验证码参数恢复为 3 次、150 秒。移除 v0.1.27 额外加入的首屏重复 GET，观察层只记录安全诊断，不再自行重发请求。

原版 vendor 登录、HTTP 和安全校验模块保持不变。手动与自动共用实现，固定账号代理不变；state、PKCE、client_id、redirect_uri 继续由 RS 原生开始接口提供，授权码仅交给 RS 原生完成接口交换和保存 RT。持续人工安全挑战仍停止并显示真实错误。

# v0.1.27

为新登录会话首个原生授权页的间歇性浏览器安全挑战增加一次有界恢复：明确的 Cloudflare 403 等待两秒后使用相同 GET、原代理、原会话及原生 state/PKCE 重取一次。后续页面、所有 POST、限流、未知拒绝和较长 Retry-After 不自动重发；持续挑战仍明确报错，不隐藏错误或无限重试。

手动与自动共用实现，授权码仍交给 RS 原生 OAuth 完成接口交换并保存 RT，设备退出及暂停保护保持。

# v0.1.26

已确认 Invalid 的暂停账号以异常状态展示，允许按同一原生 OAuth 协议自动重新授权，成功后仍保持暂停；普通手动停用及其他终态不扩大自动处理范围。

RS 提交账号凭据状态或错误原因变化后立即唤醒插件，移除插件一分钟扫描门槛，同次通知完成检查及符合条件任务的启动；周期维护仅作补漏。所有授权继续共用 RS 原生 OAuth 完成接口交换和保存 RT。

自动开关独立持久化与处理，不等待账号目录扫描或登录队列锁。修复开关被其他操作禁用、旧状态回读覆盖新设置的问题，关闭后启动登录前再次核对开关，队列保存及插件重启不会将其重新打开。

# v0.1.25

统一手动、自动、Free 恢复、Team 切换及强制选择的授权协议：插件只取得 RS 原生 state/PKCE 对应的授权码，统一由 RS 原生 OAuth 完成接口交换并首次保存 RT。移除独立 PKCE 及插件自行交换授权码的分支，原生完成失败时不切换到另一种 RT 获取路径。

设备退出进程仅接收 AT 与 ID Token。退出其他设备后由 RS 原生账号刷新接口验证并保存本次 RT，再只读核对同一本次会话仍保留、其他会话为空，最后恢复明确的调度策略。工作区元数据修正不改变原生已保存的令牌字段。

规则已写入项目 AGENTS.md，未来新增账号的授权也必须遵守。本地模拟、真实单号验收及实际部署分别记录，未通过真实设备退出验收前不宣称完成上线。

# v0.1.24

手动和自动重新授权均接入登出其他设备，继续使用三字段备注走原有登录协议。新 RT 写回后暂停空闲账号调度，唯一识别并保留本次会话，逐一撤销其他会话并读回，再刷新验证本次 RT、保存轮换结果，最后按原策略恢复调度。

无法确认本次会话、目录不完整、部分撤销、RT 刷新或写回不确定时停止并提示人工核对，已暂停账号保持暂停，不使用全部登出、不自动重放。升级前排队任务不追加新操作。保留原代理、身份、工作区、套餐与现有工作区恢复策略。

本地离线联调和构建结果不代表真实账号验收。当前设备接口来自第一方客户端内部实现，真实权限、退出效果及共享服务影响须先单号验证，见 docs/SESSION-CLEANUP.md。

# v0.1.23

修复 RS 将上游授权拒绝标记为 access_token_expired 时自动巡检漏掉的问题。新增公开 SDK 凭据终态核验，仅 expired 进入重授权；普通到期但凭据仍为 ready、状态缺失或其他异常保持跳过。入队、执行和写回前均检查最新条件。

# v0.1.22

自动开关状态独立读取，目录超时时保持真实开关状态，未确认状态前禁用操作。

# v0.1.21

凭据明确失效时支持后台自动重新授权。每分钟检查完整目录、每次最多一个、串行执行，同一异常只自动尝试一次，记录跨页面刷新和进程重启保留。

自动任务严格保留原用户、主体、工作区、套餐、代理及配置，双令牌事前校验和精确凭据版本写回后读回；人工暂停、在途、限流、封禁、单纯 AT 到期及未知异常跳过，工作区变化或不确定结果停止并提示人工处理。手动工作区恢复功能保持现有行为。

页面加入自动开关和自动任务结果，后台维护不依赖浏览器保持打开。新安装默认关闭，现有实例通过受保护管理入口开启。
