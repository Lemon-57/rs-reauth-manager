# 账号重新授权 v0.1.19

新增直接删除所选账号，修复复选框显示及 Free 授权写回的适配问题。

## 账号删除与选择

- 新增“删除所选”，直接调用 RS 原生账号删除接口，真正移除网关账号，不仅移除插件列表项。
- 按管理员要求，不增加确认弹窗、授权任务或在途请求拦截；删除成功后清理对应插件任务，其他账号和任务不变。
- 资料不齐、没有代理、排队或正在授权的账号也可选中删除；重新授权继续使用其原有资格与身份保护。
- 校验原生返回的账号和数量，并回读目录确认实际移除；响应丢失或状态不确定时提示核对，不自动重复删除。
- 选择列改用官方 UI 专用选择列，修复原文本列内边距造成的复选框裁切；固定单个图标居中，支持当前页半选状态。

## 授权适配修复

- 授权页扫描跳过普通脚本赋值、字符串、注释、比较及正则字面量，只对实际 JSON 文档累计解析预算，避免在检查工作区候选之前耗尽预算。
- 明确退回 Free 时，源记录已经为 Free 的账号可以验证并复用原个人工作区；仍要求同一用户、主体、目标工作区及真实 Free 令牌。
- 停止调度后正确接受 RS 返回的 `disabled` 状态，不再将已成功写回误报为待人工核对。
- 保留独立代理、身份校验、凭据版本 CAS 和工作区切换规则；不恢复历史失败任务，不自动批量登录。

## 兼容与边界

- RS `>=3.29.1, <3.30.0`，RPC v4、management v2、maintenance v1、manifestVersion 2；使用固定匹配 SDK 与 CLI 本机构建打包。
- 普通原工作区重新授权仍通过 RS 原生完成路径，该宿主分支的新旧令牌身份比较边界未在本次修改，详见 `docs/UPSTREAM-PARITY.md`。
- 本次隔离批处理专用的普通授权实现及账号结果报告不进入发行包；不包含并行执行、2FA 密钥轮换或周限插件改动。

## 验证与安装

- 162 项 Python、17 项 Rust、61 个 SDK 子进程 RPC 场景、16 项前端桥、26 项任务交互及 4 种复选框状态检查通过，另完成源码约定检查与前端生产构建。
- 授权恢复路径已在明确授权的真实账号上独立读回新 Free 凭据、身份及停止调度状态，验收记录不包含账号凭据；不将这些真实账号资料写入仓库。
- 删除功能只用虚构账号和模拟原生接口验收，不以删除真实账号作为发布或上线自检。
- Edge 的交互与部分截图请求超时，未将未完成的浏览器交互验收宣称为通过；复选框 DOM、官方选择列及单图标规则已有自动化覆盖。
- 下载 `personal.reauth-manager-0.1.19-x86_64-unknown-linux-gnu.tar.gz` 与同名 `.sha256` 文件，核对摘要后安装；Source code 不是安装包。
- Linux x86_64，入口 glibc 2.28+，自带协议运行环境；插件数据盘须可写、可执行，至少预留 256 MiB。
