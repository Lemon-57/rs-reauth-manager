# 账号重新授权 v0.1.4

修复小容量或禁止执行的系统临时盘导致“协议运行包解包失败”的问题，提供 Linux x86_64 安装包和 SHA-256 校验文件

## 修复

- 运行包展开后约 78 MiB，改用插件数据目录内随机、权限为 0700 的私有运行目录，不再依赖系统 `/tmp` 的容量或执行权限
- 登录前先检查 Python、TLS、协议依赖和 TOTP；环境失败时不再启动原生 OAuth 流程
- 新增管理路由 `POST api/runtime-check`，正文 `{}`，仅检查运行环境，不读取登录资料、不访问上游、不创建账号任务
- 运行目录在当前进程内复用，解包失败回收部分文件，正常退出时显式清理；强制终止或宿主崩溃可能留下运行目录
- 空间不足、权限或执行限制提供具体错误提示，不修改网关挂载、安全选项及 CPU/内存配置
- 已安装 v0.1.2 或 v0.1.3 的用户请上传此版本并确认切换到 v0.1.4；旧的失败记录不会自动重试

## 功能

- 从原账号备注读取邮箱、密码和验证器密钥，沿用账号绑定代理进行协议登录
- 使用 RS 原生授权流程换取并保存新授权，保留原启用状态、分组和代理
- 支持会员与状态筛选、分页、单号处理、串行批量队列、进度和取消
- 不显示或导出 RT，Free 账号、未绑定代理、在途请求及并发配置变化均有保护
- 运行包自带 Linux Python 和依赖，不依赖重登站或服务器安装依赖

## 安装范围

- 插件 ID：`personal.reauth-manager`
- 宿主清单兼容：RS `>=3.26.2, <3.27.0`
- 平台：Linux x86_64，插件入口要求 glibc 2.28+
- GitHub 安装仓库：`Lemon-57/rs-reauth-manager`
- 版本标签：`v0.1.4`，或留空查询最新正式发行版
- 附件中的 `.tar.gz` 是安装包，Source code 不是安装包
- 插件数据盘须可写、可执行，并至少预留 256 MiB 空间
