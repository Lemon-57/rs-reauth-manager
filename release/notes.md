# v0.1.25

统一手动、自动、Free 恢复、Team 切换及强制选择的授权协议：插件只取得 RS 原生 state/PKCE 对应的授权码，统一由 RS 原生 OAuth 完成接口交换并首次保存 RT。移除独立 PKCE 及插件自行交换授权码的分支，原生完成失败时不切换到另一种 RT 获取路径。

设备退出进程仅接收 AT 与 ID Token。退出其他设备后由 RS 原生账号刷新接口验证并保存本次 RT，再只读核对同一本次会话仍保留、其他会话为空，最后恢复明确的调度策略。工作区元数据修正不改变原生已保存的令牌字段。

规则已写入项目 AGENTS.md，未来新增账号的授权也必须遵守。本地模拟、真实单号验收及实际部署分别记录，未通过真实设备退出验收前不宣称完成上线。

# v0.1.24

手动和自动重新授权均接入登出其他设备，继续使用三字段备注走原有登录协议。新 RT 写回后暂停空闲账号调度，唯一识别并保留本次会话，逐一撤销其他会话并读回，再刷新验证本次 RT、保存轮换结果，最后按原策略恢复调度。

无法确认本次会话、目录不完整、部分撤销、RT 刷新或写回不确定时停止并提示人工核对，已暂停账号保持暂停，不使用全部登出、不自动重放。升级前排队任务不追加新操作。保留原代理、身份、工作区、套餐与现有工作区恢复策略。

本地离线联调和构建结果不代表真实账号验收。当前设备接口来自第一方客户端内部实现，真实权限、退出效果及共享服务影响须先单号验证，见 docs/SESSION-CLEANUP.md。

# v0.1.23

修复 RS 将上游授权拒绝标记为 access_token_expired 时自动巡检漏掉的问题。新增公开 SDK 凭据终态核验，仅 expired 进入重授权；普通到期但凭据仍为 ready、状态缺失或其他异常保持跳过。入队、执行和写回前均检查最新条件。

# v0.1.22

自动开关状态独立读取，目录超时时保持真实开关状态，未确认状态前禁用操作。

# v0.1.21

凭据明确失效时支持后台自动重新授权。每分钟检查完整目录、每次最多一个、串行执行，同一异常只自动尝试一次，记录跨页面刷新和进程重启保留。

自动任务严格保留原用户、主体、工作区、套餐、代理及配置，双令牌事前校验和精确凭据版本写回后读回；人工暂停、在途、限流、封禁、单纯 AT 到期及未知异常跳过，工作区变化或不确定结果停止并提示人工处理。手动工作区恢复功能保持现有行为。

页面加入自动开关和自动任务结果，后台维护不依赖浏览器保持打开。新安装默认关闭，现有实例通过受保护管理入口开启。
