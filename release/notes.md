# 账号重新授权 v0.1.20

修复个人 Free 账号加入新团队后，插件仍取得个人 Free 授权的问题。

- 识别授权页返回的 `kind: organization` 工作区，避免漏掉新加入的组织而继续使用个人工作区。
- 唯一组织只作为待验证候选；新 AT 和 ID Token 必须同时确认同一邮箱、用户、主体、目标工作区及真实 Team/Business 套餐，才写回原账号并恢复调度。
- 多个组织候选继续要求手动选择；个人标记冲突、明确的非团队套餐、身份不符或凭据版本变化均不自动写回。
- 保留原账号、分组、备注、固定代理、权重、并发和模型权限。更新插件本身不会重新登录账号，也不会重放历史任务。

兼容宿主 `>=3.29.1, <3.30.0`，RPC v4、management v2、maintenance v1。Linux x86_64，自带协议运行环境，插件数据盘需可写、可执行。

本机完成 166 项 Python、17 项 Rust、61 个 RPC、16 项宿主桥、26 项任务交互、4 种复选框状态及 214 项源码约定检查，并通过前端生产构建和静态检查。安装包内嵌协议代码与源码逐文件一致，隔离环境验证 RPC 握手、运行环境自检与正常清理，未访问真实账号。

新版已安装并在明确授权的 8 个原 Free 账号上完成真实验证：均取得新 RT，AT 和 ID Token 同时确认新工作区的 Team 套餐，原记录切换为 Team 并恢复调度，原配置保持一致。该结果只覆盖这 8 个样本，不代表所有账号或上游验证步骤均已覆盖。安装期间保留原任务历史，旧插件自然退出，网关与现有服务未重启。
