# 账号重新授权 v0.1.9

新增原工作区失效后的个人 Free 恢复，并收录自 v0.1.6 以来的统计、分组展示和布局修复。提供 Linux x86_64 安装包及 SHA-256 校验文件。

## 原工作区失效恢复

- 只有已登录会话确认原工作区不可用，并且唯一明确的个人工作区确认为同一用户的 Free 时，才进入恢复流程；缺少证据、身份不一致或工作区不明确时停止写回。
- 复用原账号绑定代理和登录会话，通过未修改的上游协议代码生成独立 PKCE、校验 state 并换取 Free 授权，不混用 RS 待完成流程的授权码和 verifier。
- 先停止原 RS 账号调度，再通过公开 SDK 的精确凭据版本校验写回同一账号，不新建账号，不修改名称、分组、代理、权重、并发限制和模型权限。
- 完整读回验证通过后显示“登录成功：原工作区已失效，已切回 Free，已停止调度”，计入本次成功；原本停用的账号仍停用。
- 常规重新授权仍走 RS 原生 OAuth 流程，保留启用状态。Free 恢复是唯一会主动关闭调度的路径，确认窗口会明确提示。
- 停用或写回结果不确定时显示需要核对，不声称恢复成功，不自动重试；历史失败记录不会被直接改成成功。
- 新授权只在私有进程管道及 SDK 二进制载荷中传输，不进入页面、任务历史或普通日志。

## 统计与展示

- “可处理”按 RS 中状态异常的适用账号统计，包含尚未补齐登录资料或代理的账号；正常访问令牌到期不等于需要更新 RT。
- “成功”和“未完成”只统计本页最近一次提交的任务，重新进入插件或刷新整个页面时归零，后台历史保留。
- 点击成功或未完成可查看本次对应账号，并清除无关搜索、会员筛选和分页位置。
- 账号后新增 RS 原生分组列，支持多个分组及分组名称搜索，未分组账号仍保留在列表中。
- 对齐顶部统计，去除下划线，收紧账号列间距，并验证窄屏下的 Free 恢复结果展示。
- 全部套餐的 OpenAI OAuth 账号继续可用，包括 Free；不影响独立周限／重置卡插件的 Free 排除规则。

## 安装

- 插件 ID：`personal.reauth-manager`
- RS 兼容范围：`>=3.26.2, <3.28.0`
- 平台：Linux x86_64，入口要求 glibc 2.28+
- GitHub 安装仓库：`Lemon-57/rs-reauth-manager`
- 版本标签：`v0.1.9`，或留空查询最新正式发行版
- 下载附件 `.tar.gz` 和 `.sha256`，核对摘要后上传并切换版本；Source code 不是插件安装包。
- 运行包自带 Python 和依赖，不需要在服务器安装依赖；插件数据盘须可写、可执行，并至少预留 256 MiB 空间。
- 更新后刷新插件页面。已有任务历史保留，不会因安装新版自动重新登录账号。

## 验证与限制

- 本机通过 29 项真实 SDK 子进程协议场景、5 项 Rust 测试、35 项 Python 测试、12 项前端桥测试、14 项 Vue 生命周期及本次任务统计场景、200 项源码约定检查。
- 35 项 Python 测试包括 17 项适配层、4 项未修改上游协议集成、9 项 Free 恢复与身份保护、5 项页面资源回归。
- 使用完成的 Linux 安装包，在无网络、非 root、只读根目录、32 MiB noexec 临时盘、128 MiB 内存和 0.25 CPU 的隔离环境，通过实际 SDK 运行环境自检和 30 项适配层、上游协议及 Free 恢复测试，验证运行目录复用与退出清理。
- 已在 RS v3.27.1 安装，实际运行版本与发行包摘要一致，环境自检通过；账号配置、历史记录及其他插件保持不变，网关及其他服务未重启。
- 已使用模拟数据验证桌面和窄屏下的成功标签、Free 套餐、停用状态及本次成功计数。
- **仍为实验性功能，尚未用真实账号验证完整 Free 恢复与写回链路。** 本次发布不执行生产账号重登、凭据写回或重置卡消费，请先在测试实例及自有测试账号上验证。
- 不绕过手机号、邮箱验证码或其他人工验证；未绑定代理、存在在途请求、并发配置或凭据变更时仍拒绝写回。
