# 0.1.55

修复导入账号在前端和后端均被限制为最多 100 行的问题。超过 200 行时，队列仅清理旧历史，不会移除新批次或对空队列执行删除。

保留 500 KiB 内容和宿主 256 KiB 状态记录保护。整批格式、大小写无关邮箱去重及完整目录检查通过后，先保存全部非敏感任务，再逐行执行；容量不足整批拒绝。密码、2FA、RT 仍只保留在当前插件进程内存，不重放不确定结果。

验证：32 项 Rust 单元测试、clippy、前端类型检查及构建、40 项页面批量场景、83 项原生协议回归、6 项大批量 RPC 场景通过。大批量测试覆盖 101、200、201、242、500 行、尾行格式/重复、存储容量拒绝、幂等提交、串行推进和整批取消，均使用虚构账号。
