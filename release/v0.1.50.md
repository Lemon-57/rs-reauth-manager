# v0.1.50

全选重新授权改为持久化后台待办队列，整批保存成功后再逐个执行。移除手动重新授权的 100 个账号提交及队列数量限制，不要求用户手动分批；242 个及 1001 个账号的整批入队、去重、回读与取消均已测试。

待办仅保存请求标识和账号 ID，执行到该账号时再读取备注及原固定代理。刷新、关闭页面不影响后台队列。插件交接后保留尚未开始的待办；已开始但结果不确定的授权继续保留核对状态，不自动重放。手动批次优先于自动扫描，仍只有一个授权执行者与一个正在执行的账号。

队列写入沿用宿主 CAS 和单记录 256 KiB 存储边界，默认字段按旧读者支持的方式省略，并在必要时清理最早的已结束历史；不删除待办或在途任务。提交预留执行进度空间，保存失败时整批不生效。所有界面回复仍返回完整任务字段，支持取消单个待办或整批取消；取消未开始的账号不会发起登录。

回退须等待所有待办及在途授权完成或由用户明确取消，再切换旧版本；旧版本无法执行新增的待办记录。安装制品保留 0.1.49 的协议运行包及身份校验修复。
