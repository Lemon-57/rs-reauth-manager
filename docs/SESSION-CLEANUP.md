# 授权完成核验

从 0.1.42 起，按用户要求移除设备目录读取、其他会话撤销及设备复核。原生 OAuth 登录仍使用其内部会话和设备标识，但不再请求 ChatGPT 设备管理接口，也不把设备标识作为授权完成或启用的必要条件。

手动、自动、批量、新增与 Free 工作区恢复统一使用 RS 原生 OAuth 开始、插件授权码回调、RS 原生完成接口；插件不自行交换或写入 RT。原生保存后核验邮箱、用户、主体、工作区、套餐、固定代理和精确凭据版本，再调用 RS 原生账号刷新接口核对 RT 轮换保存结果，最后按既有启停策略恢复并读回。

Team/Business 在身份核验通过后归入唯一启用的 GPT Pro。新增 Team 和明确 Free 升级成功后默认启用；普通已暂停账号、自动任务的人工暂停保护、Free 恢复及强制工作区策略保持原有规则。配置或凭据版本变化、有在途请求、刷新或保存结果不确定时停止，不自动重放。

升级保留历史任务及诊断，不把旧失败改写为成功。旧 logoutOthers 和 cleanupStarted 字段只用于兼容读取历史，不再触发设备操作。更新前必须等待授权队列空闲，更新本身不恢复已有暂停账号。已知仅因旧设备步骤被暂停的账号，须单独核对最新授权和原暂停原因后处理。

所有协议及构建测试在本机执行；真实验收核对原生回调保存、RT 刷新及最终账号读回，不用 HTTP 成功代替身份、保存和状态确认。
