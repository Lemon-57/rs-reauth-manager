# 账号导入

工具栏选择“导入账号”，可一次输入多行，每行一个账号，三字段与四字段可混合，每批最多 100 行：

```text
邮箱----密码----2FA
邮箱----密码----2FA----RT
```

三字段通过受保护管理入口创建 RS 原生 OAuth 流程，插件仅返回授权码回调，RS 交换和保存 RT。优先选择唯一明确的 Team/Business；仅有唯一明确 Free 时保存 Free 并保持暂停。多个团队不自动任选。原生保存后继续现有设备退出、刷新、身份和启停读回流程。

四字段先通过现有受保护 RT 导入接口验证提供的 RT，保存到新账号。双令牌证明邮箱、用户、主体、工作区、套餐及有效期后，Team/Business 直接启用，不发起账密登录或设备退出。Free 保持同一账号及固定代理，进入普通手动重新授权队列，按现有唯一 Team 成员资格规则处理。不能从 RT 的字符串外观推断套餐。

整批先校验格式并按忽略大小写的邮箱去重，任一行格式无效、批内重复或目录已存在时整批不入队。校验通过后按行串行处理，每行显示独立进度、结果及取消入口；一行失败不重放该行，继续处理下一行。关闭浏览器后由后台继续；插件进程重启时未完成行标记中断，需核对后手动处理，不从持久状态重建密码或 RT。

导入前完整分页去重，邮箱忽略大小写；已存在的账号拒绝新增，不覆盖有效凭据、不分配第二个代理。重复 requestId 只读回原回执。结果不确定、传输中断或原生完成失败时提示核对，不自动重放。

备注严格为前三字段，RT 不进入备注、任务状态、普通日志或浏览器存储。提交或关闭弹窗后清空输入。任务状态只保存请求标识、账号标识和安全状态；管理员认证只在当前调用及未完成工作进程的内存中存在。

## 受保护管理集成

管理员需设置 `protectedManagementUrl` 为本机回环 HTTP 地址并带端口。导入文本不能控制管理 URL；插件仅向固定的四条路径转发原管理员认证。不配置时拒绝导入，普通重新授权继续使用原逻辑。

适配入口须先校验原管理员会话，使用当前有效管理服务分配预建槽、验证固定认证出口并登记原生 OAuth flow，返回该 flow 的确切代理。原生完成与 RT 导入必须交给同一受保护管理层，以保留永久 IPv6 归属、不复用、消费者保护及账号绑定。不能用临时代理或直接宿主导入替代这项集成。

公开插件不内置站点管理员凭据、真实账号、代理认证或服务器配置。部署适配器属于站点运维材料，不随插件公开发布。
